# Лабораторная работа №4 — Методы оптимизации

Решение многоэтапной задачи управления инвестиционным портфелем методом динамического программирования.

Автор: Бен Шамех Абделазиз, группа К3339, поток 1.2

## Файлы

- `lab4.py` — основная программа (функция Беллмана, перебор допустимых управлений, прямой проход)
- `lab4_test.py` — 16 тестов (pytest), включая сравнение с полным перебором
- `lab4_extra.py` — дополнительное задание: дерево исходов и статистика по 27 исходам
- `decision_tree.txt` — полное дерево исходов (создается `lab4_extra.py`)
- `Отчет_МетОпт_лр4.pdf` — отчет

## Запуск

```
python lab4.py          # решение и стратегия (около 10 секунд)
python lab4_extra.py    # дерево исходов, создает decision_tree.txt
python -m pytest -v lab4_test.py
```

Нужен Python 3.8+. Для тестов: `pip install pytest`.
