1. Постановка задачи
Необходимо решить задачу линейного программирования:
\[
Z=x_1+2x_2+3x_3+x_4\rightarrow\min
\]
при ограничениях:
\[
x_1+2x_2+x_3\leq 7,
\]
\[
x_2+x_3+x_4=6,
\]
\[
x_1+x_4\geq 2,
\]
\[
x_1,x_2,x_3,x_4\geq0.
\]
Итоговое оптимальное решение:
\[
\boxed{x^*=(0,0,0,6)}
\]
\[
\boxed{Z_{\min}=6}
\]
2. Метод решения
Задача решается симплекс-методом с использованием вспомогательной задачи.
Сначала исходная задача приводится к каноническому виду. Для этого:
- для ограничения вида \(\leq\) добавляется добавочная (slack) переменная;
- для ограничения вида \(\geq\) вычитается surplus-переменная;
- если после этого в строке нет готовой базисной переменной, вводится искусственная переменная.
Для варианта 2 канонический вид имеет вид:
\[
x_1+2x_2+x_3+x_5=7,
\]
\[
x_2+x_3+x_4=6,
\]
\[
x_1+x_4-x_6=2.
\]
Здесь \(x_5\) — slack-переменная, а \(x_6\) — surplus-переменная.
Для второй и третьей строк сразу нет полного начального базиса, поэтому вводятся искусственные переменные \(x_7\) и \(x_8\).
Строится вспомогательная задача:
\[
W^a=x_7+x_8\rightarrow\min.
\]
Её цель — удалить искусственные переменные из базиса. В результате:
\[
W^a=0,
\]
поэтому исходная задача имеет допустимое решение.
После этого решается исходная задача симплекс-методом. В последней таблице все оценки в строке цели неотрицательны, поэтому достигнут оптимум.
3. Результат ручного решения
В результате ручного решения получено:
\[
x_1=0,\qquad x_2=0,\qquad x_3=0,\qquad x_4=6.
\]
Следовательно,
\[
Z=0+2\cdot0+3\cdot0+6=6.
\]
Проверка ограничений:
\[
0+0+0\leq7,
\]
\[
0+0+6=6,
\]
\[
0+6\geq2.
\]
Все ограничения выполнены.
Подробное ручное решение находится в файле с фотографией/сканом рукописного решения.

5. Проверка программой
Для дополнительной проверки использовалась реализация симплекс-метода из лабораторной работы.
Программа:
1. читает задачу из task.txt;
2. приводит её к каноническому виду;
3. определяет, существует ли готовый базис;
4. при необходимости строит вспомогательную задачу с искусственными переменными;
5. решает вспомогательную задачу;
6. решает исходную задачу симплекс-методом;
7. восстанавливает значения исходных переменных и вычисляет значение целевой функции.
Для вычислений используются точные рациональные числа Fraction, поэтому при ручной проверке не возникает ошибок округления.
Для варианта 2 программа получила:
\[
\boxed{x=(0,0,0,6)}
\]
\[
\boxed{Z_{\min}=6}.
\]
Таким образом, ручное решение, Excel Solver и программная проверка дают одинаковый результат.
